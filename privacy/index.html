Политика конфиденциальности

Версия 1.0 · Дата вступления в силу: 01.11.2026

1. Кто отвечает за обработку данных

Оператор: Индивидуальный предприниматель Аббазян Иван Сергеевич, использующий DEMIXRA как название игрового бренда. Контакт для обращений: demixra@list.ru.

2. На какие приложения распространяется политика

На мобильные игры и приложения DEMIXRA, в которых размещена ссылка на эту политику. На будущие игры — при условии, что документ корректно описывает обработку данных в них.

3. Сохранение игрового прогресса

Игры могут сохранять на устройстве прогресс, очки, настройки и игровые достижения. При отсутствии облачных функций эти данные остаются локальными.

4. Реклама

В бесплатных играх может применяться Yandex Mobile Ads SDK. В зависимости от реализации и разрешений рекламный поставщик может обрабатывать рекламные идентификаторы, IP-адрес, сведения об устройстве, показах, взаимодействии с рекламой и диагностические данные.

Сведения о рекламной платформе и её документации: Yandex Mobile Ads.

5. Цели обработки и получатели

Игровые данные используются для работы приложения и сохранения прогресса. Данные рекламного SDK могут обрабатываться для показа рекламы, измерения эффективности, обеспечения безопасности и предотвращения мошенничества. Получателем рекламных данных может являться Яндекс и предусмотренные его сервисами участники обработки.

6. Сроки хранения и удаление данных

6.1. Локальные игровые данные

Игровой прогресс, заработанные очки, настройки и другие локальные данные сохраняются на устройстве пользователя в течение периода использования соответствующего приложения.

Разработчик не устанавливает фиксированный срок автоматического удаления таких данных.

Пользователь может удалить локальные игровые данные средствами операционной системы или с помощью функций сброса прогресса, если они предусмотрены приложением.

6.2. Данные рекламных сервисов

При использовании рекламы Yandex Mobile Ads определённые технические данные могут обрабатываться и храниться рекламным партнёром.

Сроки хранения таких данных определяются применимыми правилами рекламного партнёра, целями обработки и требованиями законодательства.

DEMIXRA не устанавливает самостоятельно сроки хранения данных в системах рекламного партнёра.

6.3. Запросы пользователей

По вопросам обработки и удаления персональных данных пользователь может обратиться по адресу: demixra@list.ru.

Запросы рассматриваются в соответствии с применимым законодательством. Если данные обрабатываются рекламным партнёром, пользователю может потребоваться обратиться непосредственно к соответствующему оператору данных.

7. Международная обработка и защита данных

Мобильные игры и приложения DEMIXRA могут использоваться пользователями из разных стран.

Для отображения рекламы в приложениях может использоваться Yandex Mobile Ads SDK. При работе рекламного SDK определённые технические данные и идентификаторы устройств могут передаваться рекламному партнёру.

В зависимости от используемой инфраструктуры рекламного партнёра обработка данных может осуществляться за пределами страны проживания пользователя. Такая обработка должна соответствовать применимому законодательству о защите персональных данных.

Для защиты данных при передаче Yandex Mobile Ads SDK использует шифрование по протоколам HTTPS/TLS.

DEMIXRA принимает меры по соблюдению применимых требований законодательства о защите персональных данных, включая требования к международной передаче данных и получению согласия пользователей в случаях, когда оно необходимо.

8. Дети

Мобильные игры DEMIXRA могут иметь различные возрастные рейтинги в зависимости от содержания конкретного приложения.

Возрастной рейтинг каждой игры указывается на странице приложения в соответствующем магазине.

При использовании рекламных технологий DEMIXRA учитывает требования законодательства о защите детей и правила распространения рекламы, установленные соответствующими платформами.

В приложениях, предназначенных для детей, могут применяться дополнительные ограничения на сбор персональных данных, персонализацию рекламы и использование рекламных идентификаторов.

Реклама, предназначенная для показа несовершеннолетним пользователям, должна соответствовать применимым возрастным ограничениям и требованиям законодательства.

Если необходимый уровень защиты детской аудитории не может быть обеспечен, рекламные объявления такой аудитории не показываются.
